What you need

  • A Heltec WiFi LoRa 32 V3/V4, RAK4631, or T114, and a USB data cable.
  • Internet for firmware downloads. ESP installation requires desktop Chrome or Edge over HTTPS; nRF52840 downloads work in other modern browsers.
  • Close serial monitors and other apps using the radio’s USB port.

Match the board markings. USB identifies the processor, not the board model.

For V4 OLED, choose V4.2 / GC1109 or V4.3 / KCT8103L to match your hardware revision. These profiles do not drive the optional TFT display. For LILYGO, match T-Deck, Plus, Pro v1.0, Pro v1.1, or Pro Max. Audio and cellular editions use the same profile for their board revision; choose a radio preset matching its 433/868/915 MHz hardware.

RAK4631 / T114: which SoftDevice version?

Double-press Reset, open the bootloader’s USB drive, and read the SoftDevice line in INFO_UF2.TXT. The bootloader version is a different number.

3. Download nRF52840 firmware

Match the installed S140 version before downloading. The browser verifies the application’s memory layout and checksum; it cannot inspect your radio automatically.

  1. Verify and save the matching file below.
  2. For UF2, double-press Reset and copy it to the bootloader’s USB drive. The radio restarts after copying.
  3. For HEX, preserve the installed matching SoftDevice and bootloader. Do not mass-erase the chip.
  4. Install meshit-android-debug.apk from the same release. Open Settings → Bluetooth → Connect. RAK4631 and T114 have no Wi-Fi.

After installing on Heltec V3 / V4

  1. Read the meshit-… Wi-Fi name and eight-digit numeric password on the radio’s OLED. The password is a four-digit PIN repeated twice. With no working supported display, the password is 12345678. No serial monitor is needed with current firmware.
  2. Join that Wi-Fi and open http://192.168.4.1.
  3. Choose Meshtastic or MeshCore, then region and preset. MeshOregon is available under Meshtastic / US.
  4. To join your home Wi-Fi, save its details in Settings and restart the radio. Open http://meshit.local on your local network. For Bluetooth, disconnect Wi-Fi clients, then use Find radios → Connect in the companion. ESP32 pairing uses the last six digits of its setup Wi-Fi password.
My radio does not show setup credentials

Install firmware with on-screen setup support. Current firmware shows the AP name, numeric password, and setup address on the Heltec V3/V4 OLED. If the display is absent or fails to initialize, join meshit-… with password 12345678. Older firmware may use a different password. RAK4631 and T114 have no Wi-Fi; use Bluetooth.

The USB port does not appear

Try another data cable and close any serial monitor. For Heltec V3/V4, hold BOOT, press and release Reset, then release BOOT and select its bootloader port.

Will an update keep my chat?

An app-only update preserves storage when the board and partition layout match and “Erase device” stays unchecked. Fresh-install images replace all flash contents, including stored chat and settings, regardless of that checkbox.
