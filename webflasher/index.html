After installing on Heltec V3

  1. Read the Meshit-… Wi-Fi name and eight-digit numeric password on the radio’s OLED. The password is a four-digit PIN repeated twice. With no working supported display, the password is 12345678. No serial monitor is needed with current firmware.
  2. Join that Wi-Fi and open http://192.168.4.1.
  3. Choose Meshtastic or MeshCore, then region and preset. MeshOregon is available under Meshtastic / US.
  4. To join your home Wi-Fi, save its details in Settings and restart the radio. Open http://meshit.local on your local network. For Bluetooth, disconnect Wi-Fi clients, then use Find radios → Connect in the companion. ESP32 pairing uses the last six digits of its setup Wi-Fi password.
My radio does not show setup credentials

Install firmware with on-screen setup support. Current firmware shows the AP name, numeric password, and setup address on the Heltec V3 OLED. If the display is absent or fails to initialize, join Meshit-… with password 12345678. Older firmware may use a different password. RAK4631 has no Wi-Fi; use Bluetooth.

The USB port does not appear

Try another data cable and close any serial monitor. For Heltec V3, hold BOOT, press and release Reset, then release BOOT and select its bootloader port.

Will an update keep my chat?

An app-only update preserves storage when the board and partition layout match and “Erase device” stays unchecked. Fresh-install images replace all flash contents, including stored chat and settings, regardless of that checkbox.
