# 💩 meshit wiki

Small, threaded LoRa chat on Heltec V3/V4, LILYGO T-Deck / Plus / Pro / Pro Max, RAK4631, and T114, using nearby Meshtastic or MeshCore infrastructure.

**[Install firmware](https://meshit.pdxlocs.com)** · **[Release downloads](https://github.com/pdxlocations/meshit/releases)**

## Start here

2. [Connect and configure](Connection-and-Settings.md) your radio and local network.
3. [Use rooms, replies, upvotes, and downvotes](Using-Meshit.md).

LILYGO T-Deck, Plus, Pro v1.0/v1.1, and Pro Max have [standalone screen/keyboard chat](T-Deck.md) alongside Wi-Fi/Bluetooth companions. All five profiles build successfully and pass host tests; hardware verification remains. Bluetooth and Wi-Fi default to Off and can be enabled separately in on-device Settings.
